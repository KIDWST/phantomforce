# Shadowbearer third-party assets

## Currently used

- Quaternius Medieval Village assets already imported under `Content/Phantom/External/Quaternius/MedievalVillage`.
- Existing project-curated and generated Phantom assets under `Content/Phantom/Curated` and `Content/Phantom/Generated`.
- Existing CC0 aliases under `Content/Phantom/External/CC0/Aliases`.
- Unreal Engine sample/engine assets already included in the project runtime where referenced by existing character and material systems.
- User-provided Shadowbearer concept board, stored as `app/assets/phantomplay/shadowbearer-cover.png`, for product art and internal visual comparison.

## Rules

- Do not import assets from an external source without a recorded license and provenance entry.
- Do not replace authored materials with prototype basic-shape materials.
- Keep imported source namespaces intact to preserve attribution and update traceability.
- Public shipping art must not claim a visual asset is in-game when it is only a concept reference.

# Shadowbearer asset-gap report

## Implemented from the current licensed library

- Bramblewick Dawn market dressing, bell tower, carts, benches, bags, flowers, villagers, and warm practical lighting.
- Shadowfall replacement dressing with corrupted roots, restrained crystal scars, lowered sun, violet/charcoal grading, abandoned NPC state, and the persistent Dawnlamp scar.
- Same-map state transition, Pale Warden encounter, first solid-shadow traversal object, restoration interaction, save persistence, and deterministic capture overrides.
- Seven named townspeople: Sera, Mara, Tess, Kael, Brann, Orin, and Ilyra.
- Human-scale player capsule, grounded movement, full orbit camera, sprint, crouch, jump/climb, guard/parry, dodge, lock-on, and locomotion animation graph from the existing production foundation.

## Remaining authored-asset opportunities

These are enhancement opportunities, not substitutes for the playable vertical slice:

- Dedicated Zane character mesh with teal cloak, lantern harness, facial rig, and authored combat set.
- Dedicated Pale Warden skeletal boss with bespoke stagger, grab, and Shadowfall-finisher animation.
- Purpose-built Dawnlantern projector VFX showing the light ray, receiving surface, and resulting tangible shadow.
- Bramblewick architecture variants with explicit Dawn and corrupted material instances.
- Original creature roster, interior sets, cinematic dialogue cameras, and authored music/SFX package.
No unlicensed marketplace asset is required by the current implementation. Any future acquisition must record source, license, version, import location, and shipping rights before use.

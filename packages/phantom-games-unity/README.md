# Retired Flagship Unity Migration Source

This directory is not registered with PhantomPlay and is not a runtime fallback for PhantomStrike, Phantom Ages, or Phantom Legends.

The three flagship games moved to `packages/phantom-games-unreal`. This Unity tree remains temporarily as migration evidence for source logic, generated key art, third-party model licenses, and asset provenance until the Unreal replacements are compiled and visually verified.

PhantomPlay still supports unrelated Unity uploads through its normal per-game runtime detection. Retiring these three Unity implementations does not remove Unity compatibility from the platform.

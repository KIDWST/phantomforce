# Repository Fit: PHANTOMStore AI Products

## Baseline

- Source: `origin/main`
- Baseline commit: `fb581474`
- Isolated branch: `codex/phantomstore-ai-products-20260817`
- Served deployment checkout: intentionally untouched

The canonical repository already contains a broad PhantomStore marketplace and production server. The master brief adds ten independently useful domain systems and 5,400 engineering tickets. Folding that unfinished surface into the served marketplace would make existing release behavior dependent on incomplete products. This implementation therefore adds one isolated workspace package with no third-party runtime dependencies and no route activation in the production server.

## Implemented boundary

The package implements a real local vertical slice for each product: governed workspace access, purpose consent, product-specific input schema, evidence/provenance, durable versioned artifact, deterministic domain analysis, explicit input/formula disclosure, job state, human review, audit, export, archive/restore/delete, diagnostics, seeded demo, responsive UI, and tests.

The package is not a deployment and does not activate external model providers, billing, public datasets, geocoding, media ingestion, object storage, notifications, or remote telemetry. Every master-prompt ticket is present in the machine-readable ledger. Only ticket behavior directly backed by implementation and test evidence is marked implemented; the rest is deferred.

## Product boundaries

These products share governance primitives but not a generic chat surface or a generic domain object. Each catalog record owns its field schema, deterministic calculator, metrics, modules, artifacts, sample data, non-goals, and evaluation fixtures.

`PHANTOM LOOM` in this brief is dependency-and-contradiction intelligence. Its internal SKU is `phantom-loom-dependency` to avoid confusing it with the separate operational-knowledge Loom concept created in an earlier isolated prototype. The public naming collision requires owner review before publication.

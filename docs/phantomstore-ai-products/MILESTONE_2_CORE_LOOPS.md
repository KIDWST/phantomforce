# Milestone 2 Product Core Loops

All loops are deterministic local methods built from declared user inputs. They create a versioned artifact, calculate product-specific records, hold the result for human review, support source-linked export, and never present an external-model or zero-review path.

| Product | Primary module | Implemented product-specific core output |
|---|---|---|
| Oracle | Decision Canvas | Assumption ledger, scenario graph, assumption-adjusted ranking, sensitivity, decision record |
| Chronicle | Evidence Intake | Source metadata, range-aware timeline, automatic and declared contradictions, duplicate-source detection, source-linked chronology export |
| Foundry | Schema Studio | Seeded recipe, synthetic fixtures, label coverage, deduplication, immutable benchmark digest, export registry |
| Twin | Process Mapper | Resources, queues, deterministic fluid simulation, 20% demand scenario, bottlenecks, calibration state, scenario export |
| Dealroom | Deal Map | Parties, interests, BATNA, constraints, concessions, package comparison, bounded rehearsal, human-confirmed commitments |
| Blueprint | Requirements Compiler | Requirements, acceptance criteria, components, data contracts, OpenAPI subset, traceability, change impact, orphan detection |
| Terrain | Layer Catalog | Candidate scores, normalized weights, declared constraints, sensitivity, source freshness, GeoJSON export |
| Proof | Claim Decomposer | Atomic subclaims, evidence board, source registry and quality, classifications, citation integrity, circularity, proof packet |
| Loom Dependency | Corpus Intake | Versioned statements, commitment registry, confirmed/inferred dependencies, contradictions, owners/deadlines, change impact |
| Causal | Hypothesis Studio | Variable registry, DAG, confounder warnings, metric registry, power helper, result fixture, causality-limited conclusion |

Each product still exposes all twelve prescribed catalog modules in its contract. The table identifies the modules connected into the Milestone 2 executable core loop, not a claim that all 120 catalog modules are independently complete.
